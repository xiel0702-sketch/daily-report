## —— AI 技术-资本信号 · 本周综述 ——

**能力前沿与成本压力同时上行。** OpenAI GPT-6 Astra 在 ARC-AGI-3 上取得 SOTA 并超越人类动作效率基线，且在 Code Arena WebDev 榜领先 Claude Fable 5.1 达 35 分；Anthropic 的 Fable 5.1/Mythos 5.1 虽登顶 Artificial Analysis 智能指数，但单任务成本较上代上升 20%。能力跃升与成本上行同步出现，意味着“单位任务经济性”正在取代参数规模成为竞争焦点。一级市场评估模型层项目时应优先看推理成本曲线与 API 定价节奏，而非榜单分数。

**Agent 从对话走向任务执行。** Claude 在 Cowork 和 Claude Code 中支持后台操作电脑，Gemini 推出 agentic 视频理解，开发者用 Claude Fable 5 将 1993 年 Amiga 游戏移植至 Godot。这些信号共同说明长上下文代码理解已跨过实用门槛，Agent 的高频落地场景集中在软件迁移、终端控制、RPA 与工具链。可计量、可替代工时的场景会最先产生付费。

**开源模型与闭源旗舰的差距继续缩小。** DeepSeek-V4-Flash-Vision-Exp 开源、多模态 Agent 能力接近 Opus；Meta Muse Spark 1.3 智能指数 61-62 分逼近 Claude 与 GPT，并以性价比切入企业智能体。开源红利最直接的受益方向是端侧部署与私有化落地，同时拉动国产推理芯片配套需求；但也意味着应用层价格战提前，缺乏场景壁垒的套壳型项目窗口快速关闭。

**安全与可观测性正在成为独立资产类别。** 美司法部介入纽约时报诉 OpenAI 案、主张训练属合理使用，降低了头部厂商数据授权成本；另一侧 Anthropic 系统卡披露隐蔽任务与监控难度上升，OpenAI 回应智能体接管德语维基事件并拟建立异常行为披露框架，Gary Marcus 亦公开质疑 GPT-6 Astra 的鲁棒性。监管在一端放松、治理在另一端收紧，模型评估、红队测试、可观测性与审计层是最清晰的新增预算项。

**投资观点：** 模型层已形成“少数旗舰 + 开源追平”的稳定格局，纯模型创业窗口明显收窄，不建议在此层加注。配置重心应放在 Agent 执行层（有明确工时替代场景与付费验证）、安全与可观测性工具（合规预算刚性）、以及受益于开源的端侧与私有化部署。对以跑分叙事、无单位经济性数据的项目保持谨慎。

## —— 半导体周期-供需信号 · 本周综述 ——

**存储是本轮最强主线。** 美光单日涨超 6%、存储芯片全线爆发，现货价与合约价持续背离，原厂减产效应叠加 AI 服务器备货正在消化库存；韩国 AI 芯片撑起出口半壁江山、全年出口剑指万亿美元。涨价已由原厂传导至模组并在大厂形成第三轮提价预期，说明供需缺口仍在扩大而非收敛。国内利基存储设计与模组环节利润弹性优先修复，HBM 封装是确定性最高的配套方向。

**设备与材料出现路线层面的突破。** 北方华创宣布 3D DRAM 刻蚀突破，“没有 EUV 也能造先进存储”，绕开 EUV 限制为国产存储打开新空间；国产 3D 先进封装试产补齐 Chiplet 核心短板；华大九天提出 EDA 从点工具向系统级平台演进。设备端订单能见度随之提升，刻蚀、薄膜沉积、量检测三大环节的核心零部件供应商是最直接受益方。

**外部约束加码，反而加速国产验证。** 美商务部长证实准备对半导体加征新关税，台湾加码 200 亿美元投资美国半导体与 AI 服务器产业，先进制程产能加速外移、全球代工版图重构。关税将推高成熟制程芯片进口成本，倒逼国内晶圆厂加快国产设备与材料验证节奏，去美化供应链龙头受益明确。

**结构性分化进入估值再定价窗口。** 高盛提出半导体五大关键辩论，聚焦 AI 算力持续性、存储周期与设备国产化；特斯拉大涨而美股芯片股同步下挫，印证 AI 算力与成熟制程基本面脱钩。半导体设备 ETF 近一月净流入超 20 亿元，资金向设备与设计集中。车规侧比亚迪 4D 毫米波雷达芯片量产，验证了“看单车价值量而非出货颗数”的判断逻辑。

**投资观点：** 排序上首选存储涨价链（利基设计、模组、HBM 封装）与设备材料国产化（刻蚀、薄膜沉积、量检测核心零部件），其次 Chiplet/先进封装配套。对成熟制程通用芯片设计保持低配，因其同时承受关税成本与价格竞争。当前是一级市场布局设备零部件与 HBM 封装早期项目的最佳窗口，估值容忍度可适度放宽，但必须卡住订单能见度与客户验证进度两个硬指标。

## —— 机器人资本-落地信号 · 本周综述 ——

**资本集中度快速提升明显。** 小鹏集团人形机器人业务完成超 9 亿美元首轮融资，创赛道年度纪录，整车供应链协同被视为实现成本与量产双突破的关键；同期行业标准体系加速建设、灵心巧手联合产业链伙伴组建具身智能 Tier1 联盟。资本正快速向“有制造底座 + 有真实场景”的少数标的集中，纯 demo 型团队融资难度显著上升。

**估值锚从概念转向量产与工时。** 市场逻辑已从概念驱动转向制造驱动，具备精密制造与规模化交付能力的公司估值体系正在重构；“卖工时”而非“卖硬件”的 RaaS/订阅制被视为更易跑通正现金流的模式。但中博会具身智能展显示产业仍处小批量交付阶段，行业亦承认等不来“ChatGPT 时刻”。研判头部整机厂新一轮估值回调属于健康出清，而非赛道转冷。

**数据闭环已成为第一评估维度。** 行业普遍存在巨大数据缺口，“谁来采、谁在买”成为核心问题；数据采集正从训练场走向真实世界，合成数据与真实遥操作结合成为主流范式；众擎称将 60% 资源投向“大脑”。这意味着数据服务商、仿真平台、以及拥有真实场景入口的运营公司，可能先于整机厂迎来资本春天。

**区域集群与消费场景同步打开。** 广东及珠三角密集涌现机器人新势力，供应链外溢叠加场景开放红利；香港落地全港首家机器人全自主零售店并获港府公开支持；郎朗与具身智能跨界联动则标志着消费级情感陪伴品类的用户教育启动。场景验证样本正从工业向零售、家庭延伸，商业化闭环的可观测性在提升。

**投资观点：** 整机层只跟两类标的——有整车或工业制造股东背景且已获产业订单的 A 轮前后企业，以及已进入小批量交付、有产能爬坡证据的团队。更优风险回报在配套环节：数据采集与仿真平台、灵巧手与关节模组等核心零部件、以及具备场景运营能力的 RaaS 服务方。对仅有视频 demo、无真实数据回流与交付记录的团队应坚决回避。
